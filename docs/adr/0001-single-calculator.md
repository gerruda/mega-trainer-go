# ADR-0001. Один калькулятор и один набор формул

**Статус:** принято
**Дата:** 2026-10-28

## Контекст

В исходной версии было два независимых набора формул: `internal/service/calculator.go`
(Mifflin–St Jeor, несколько формул 1ПМ) и `pkg/calculator/calculator.go`
(Harris–Benedict, только Эпли). Результаты TDEE для одного и того же человека
расходились, а тесты было невозможно написать «в одном месте».

## Решение

- Единственная реализация формул — `internal/service` (пакет `service`).
- Входы и выходы — value-объекты из `internal/domain` (`WaterCalculation`,
  `OneRepMaxCalculation`, `BodyFatCalculation`, `TDEECalculation`).
- Функции возвращают ошибку `domain.ErrValidation` при некорректных входах,
  вместо молчаливых дефолтов и `NaN`/`Inf`.
- Дублирующий пакет `pkg/calculator` удалён.

## Последствия

- Один источник истины: изменение формулы — одно место, один тест.
- Сервис не зависит от транспорта и хранилища — тестируется табличными тестами.
- Пользователь видит понятную ошибку вместо `+Inf %` при некорректных измерениях.
